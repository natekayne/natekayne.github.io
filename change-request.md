# Change Request

## Proposed Change

The proposed change is to add an embedded Google Map to my Midterm Project website that shows my hometown. The map would be placed in a section where it fits with the rest of the website and would allow visitors to see the location without leaving the page.

## Reasons for the Change

The instructor is the stakeholder requesting this change. The map could make the website more personal and interactive while also giving visitors more information about where I am from. It would also add another visual feature instead of only using text and images.

## How This Change Will Add Value

Adding the Google Map would make the website more useful and more interesting for visitors. Instead of only reading the name of my hometown, they would be able to actually see where it is located. I think this would be considered scope discovery instead of scope creep because the change has a clear purpose, adds value, and is being reviewed before it is added.

## How This Change Will Affect the Constraints

- **Time:** This change would take some extra time because I would need to add the map, make sure it fits correctly on the page, and test it to make sure it works.

- **Quality:** The quality of the website could improve because the map would add another interactive feature and give visitors more information.

- **Budget:** There should be little to no impact on the budget because adding a standard embedded Google Map should not require any extra software or paid tools.

Overall, I think the change would be worth adding because it gives the website more value without causing a major impact on the project's time, quality, or budget.
